1. Введение
1.1. Что это за программа
SchoolPlanner — десктопное приложение для составления школьного расписания. Программа автоматически распределяет уроки по дням недели с учётом множества ограничений: занятости учителей, кабинетов, методических дней, нагрузки по классам.

1.2. Для кого
Завучи — для составления расписания на четверть или год.

Директора — для контроля нагрузки.

Учителя — для просмотра своего расписания.

1.3. Ключевые возможности
📅 Автоматическое составление расписания — на базе OR-Tools CP-SAT.

👩‍🏫 Учителя — ФИО, предметы, запрещённые слоты (методический день).

🏫 Классы — название, количество учеников.

📚 Предметы — часы по каждому классу.

🚪 Кабинеты — вместимость, спец. кабинеты (физика, химия).

🚫 Запрещённые слоты — учитель не может вести урок в это время.

🔍 Умный советчик — подсказывает, что не так до составления.

✏️ Редактирование расписания — клик по уроку → клик по клетке.

🎨 Цветные ячейки — каждый предмет своим цветом.

📊 Экспорт в Excel — все данные и расписание в один файл .xlsx.

🔑 Демо-версия — до 5 классов бесплатно, полная — по ключу.

1.4. Системные требования
ОС: Windows 10/11 (64-бит)

ОЗУ: 4 ГБ

Интернет: не требуется

Установка: не требуется (один .exe)

4. Как работает программа
4.1. Общий поток
ЗАПУСК → Проверка лицензии

ЗАПОЛНЕНИЕ → Учителя, классы, предметы, кабинеты

АНАЛИЗ → advisor.py ищет проблемы

РЕШЕНИЕ → scheduler.py (OR-Tools)

РЕЗУЛЬТАТ → Расписание на экране

ЭКСПОРТ → Excel

4.2. Подробно по шагам
Шаг 1. Запуск
Программа проверяет license.py — есть ли ключ активации. Если есть — полная версия. Если нет — демо (баннер, ограничение 5 классов).

Шаг 2. Заполнение данных
Пользователь вводит: учителей, классы, предметы, кабинеты. Данные сохраняются в school_data.json автоматически.

Шаг 3. Анализ (advisor.py)
Программа проверяет: есть ли учителя у каждого предмета, не превышает ли нагрузка класса 35 часов, хватает ли кабинетов.

Шаг 4. Решение (scheduler.py)
OR-Tools строит модель. Ограничения: 1 класс — 1 урок, 1 учитель — 1 урок, 1 кабинет — 1 урок. Запреты: методический день. Обычно 2–5 секунд.

Шаг 5. Результат
Расписание по классам и по учителям. Каждый предмет цветной. Можно кликнуть и переместить.

Шаг 6. Экспорт (excel_export.py)
Кнопка «📊 Экспорт в Excel» → создаёт .xlsx. Вкладки: расписание, по учителям, списки данных.

5. Ключевые алгоритмы
5.1. Решатель расписания (OR-Tools CP-SAT)
Задача: распределить N уроков по 5 дням × 7 слотам без конфликтов.

Модель:

Переменные: x[lesson][day][slot] = 0 или 1

Ограничения:

sum(x[lesson][][]) == 1

Для каждого класса/дня/слота: сумма ≤ 1

Для каждого учителя/дня/слота: сумма ≤ 1

Для каждого кабинета/дня/слота: сумма ≤ 1

Запрещённые слоты: x = 0

Решение: CP-SAT перебирает умно, отсекая невозможные варианты.

Время: обычно 1–5 секунд.

5.2. Умный советчик (advisor.py)
Проверки:

Есть ли учителя у всех предметов?

Не превышает ли нагрузка класса 35 часов?

Хватает ли кабинетов по вместимости?

Не превышает ли нагрузка учителя 35 слотов?

Вывод: список проблем с рекомендациями.

6. Лицензия
6.1. Демо-версия
Ограничение: не более 5 классов.

Баннер сверху с предложением активации.

Кнопка «🔑 Ввести ключ».

6.2. Активация
Ключ формата SP-XXXX-XXXX-XXXX.

Проверяется офлайн по алгоритму md5(соль + номер).

Сохраняется в %APPDATA%\SchoolPlanner\license.json и %LOCALAPPDATA%.

При обновлении программы — ключ не теряется.

6.3. Генерация ключей
keygen.py — только у разработчика.

Генерирует ключи по номерам.

Не публикуется в открытых источниках.

7. Сборка и запуск
7.1. Запуск из исходников
pip install -r requirements.txt
python desktop_app.py

7.2. Сборка в .exe
flet pack desktop_app.py --name "SchoolPlanner_v2.1.0" ^
--add-data "advisor.py;." ^
--add-data "excel_export.py;." ^
--add-binary "C:\Windows\System32\msvcp140.dll;." ^
--add-binary "C:\Windows\System32\vcruntime140.dll;." ^
--add-binary "C:\Windows\System32\vcruntime140_1.dll;." ^
-- --hidden-import ortools --collect-all ortools

7.3. Что получается
Папка dist/SchoolPlanner_v2.1.0/. Внутри .exe и все зависимости. Можно передать пользователю — работает без Python.
