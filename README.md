\# SchoolPlanner — исходный код (приватный)



Генератор школьного расписания. Полная версия.



\## 📁 Структура проекта



| Файл | Что делает |

|---|---|

| `desktop\_app.py` | Основное приложение (Flet UI) |

| `scheduler.py` | Решатель OR-Tools CP-SAT |

| `advisor.py` | Умный советчик (анализ данных) |

| `storage.py` | Сохранение/загрузка JSON |

| `models.py` | Модели данных |

| `license.py` | 🔑 Управление лицензией |

| `keygen.py` | 🔑 Генератор ключей (только для разработчика) |



\## 🚀 Запуск



```bash

pip install -r requirements.txt

python desktop\_app.py
